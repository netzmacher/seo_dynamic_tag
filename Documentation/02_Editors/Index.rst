Editors
=======

This is the section for TYPO3 editors.

TYPO3 editors

* maintain the content of a website

* and don't need to know anything about TYPO3 integration (administration) nor TYPO3 development.


Nothing to do but ...
---------------------

Editors have nothing to do than:

* optimise your content for search engines in principle.


... Search Engine Optimization (SEO)
------------------------------------

* If you are working with the default content of TYPO3 like content elements,
  please maintain the keywords and description of the current page.
  Keywords and description are part of the page properties.
* If you are working with records - usualy delivered by extensions like
  news, Organiser_ or `Quick Shop`_ for example - please maintain
  the keywords and description of the current record. The record should
  have this properties but must not.


In case of trouble
------------------

You can check the effect of your SEO in the frontend in the header of the HTML document.
See :ref:`Image SEO Frontend <figure_seo_frontend>`.

If the meta tags keywords and description are missing or filled with default values,
please ask your TYPO3-Integrator, why SEO doesn't work.
