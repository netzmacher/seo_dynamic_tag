What does it do?
================

SEO Dynamic Tag supports the Search Engine Optimisation of your TYPO3 website.

You can generate HTML tags for records of every TYPO3 extension automatically for the tags:

* <title>

* <link rel="canonical">

* <meta name="author">

* <meta name="description">

* <meta name="keywords">

* <meta itemprop="...>

* <meta property="og:...>

* <meta name="twitter:...>
