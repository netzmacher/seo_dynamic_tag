Integrators
===========

This is the section for TYPO3 integrators.

TYPO3 integrators

* maintain this extension by the extension manager, if it's supported

* include static templates and

* configure SEO Dynamic Tag by the TYPO3 User Interface, the :ref:`Constant Editor <integrator-configuration-constanteditor>`

Usually there shouldn't be any need, to edit TypoScript code directly.
