Quick Start
===========


Workflow
--------

* Install the extension with the extension manager.

* Include the static template: SEO [1] (seo_dynamic_tag)

* Configure SEO Dynamic Tag by the :ref:`User Interface <integrator-configuration-constanteditor>`.


Downwards-Compatibility
-----------------------

If you are using the deprecated SEO Dynamic Tag 2, you don't need to update your configuration for SEO Dynamic Tag 3.

SEO Dynamic Tag 3 is downwards compatible. Please refer to :ref:`integrator-downgrade`.
