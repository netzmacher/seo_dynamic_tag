What does it do?
================

SEO Dynamic Tag supports the Search Engine Optimization of your TYPO3 website.

You can generate search HTML tags for records of every TYPO3 extension automatically for the

* <title>-tag

* <link rel="canonical">-tag

* <meta name="author">-tag

* <meta name="description">-tag

* <meta name="keywords">-tag

SEO Dynamic Tag has a user interface for the configuration.

If you will have any need, you can configure SEO Dynamic Tag by TypoScript directly.
