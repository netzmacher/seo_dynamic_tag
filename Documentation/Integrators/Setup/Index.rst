Setup
=====

* Install this extension

Root page

* Include the static template "SEO [01] – MUST PLACED BELOW OF ALL OTHER TEMPLATES"

* Place the template below all other templates


Extension templates
-------------------

* If you are using an extension, which uses SEO Dynamic Tag, include the SEO Dynamic Tag
  template of this extension at the root page.

* Template MUST placed above the template "SEO [01] ..." from above.

See :ref:`Ready-for-use extensions <integrator_extensions>`


Own extension
-------------

If you like to use SEO Dynamic Tag for an extension, which hasn't a ready-to-use-template,
please setup SEO Dynamic Tag by yourself. See: 

* :ref:`Developers > Setup <developer_setup>`
